# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Fixed

- Demo sets Project Settings → Application → Config → Version (`0.1.0`, matching export presets) so in-game `{{APP_VERSION}}` is filled without relying on the Android package fallback.

## [0.2.3] - 2026-08-05

### Fixed

- In-game `{{APP_VERSION}}` no longer stays empty when `application/config/version` is unset: Android falls back to the installed package `versionName`. Prefer setting Project Settings → Application → Config → Version so desktop/iOS match too.

## [0.2.2] - 2026-08-05

### Fixed

- Android overlay strings now escape apostrophes/quotes as `\'` / `\"` for aapt2. Using `&apos;` made English body text like `what's` fail resource merge (`unescaped apostrophe` / misleading unicode-escape errors).

## [0.2.1] - 2026-08-05

### Fixed

- Android localization now maps Indonesian (`id`) to `values-in` (and Hebrew/Yiddish to their legacy resource codes), matching Android resource-folder rules.

## [0.2.0] - 2026-08-05

### Added

- Runtime GDScript helper `QuickActionsAppShortcuts.get_feedback_data(locale)` for extracting the localized recipient and raw templates, plus rendered subject/body values with diagnostic placeholders filled. The game remains responsible for triggering mail. The editor plugin explicitly packs the shared `.cfg` into exports.

### Changed

- Asset Library / archive downloads now include only `addons/` and `ios/plugins/`; LICENSE, README, CHANGELOG, and notices ship inside the addon folder.

### Fixed

- Runtime `.cfg` packing now runs from the active Android/iOS export hooks, so in-game data is included reliably in Remote Deploy and normal exports.
- iOS export no longer registers a second `InfoPlist.strings` for locales already generated by Godot project translations. Localized shortcut titles are merged into Godot's files after the Xcode project is generated.
- iOS mailto bodies now encode line breaks as RFC 6068 CRLF (`%0D%0A`) so mail clients preserve them.
- Android export now writes `\n` escapes into overlay `strings.xml`, so `body_template` line breaks survive aapt (raw newlines were collapsed and overrode the AAR defaults).

## [0.1.0] - 2026-08-03

Initial public release.

### Added

- Editor export plugin for Godot **4.7+** (no runtime GDScript / scene node required)
- Static **Send feedback** home-screen shortcut on Android (App Shortcuts) and iOS (Quick Actions)
- Config file `res://quick_actions_app_shortcuts.cfg` (recipient, title, icon, subject/body templates)
- Locale overlays via `[feedback.<locale>]` sections
- Android trampoline activity that opens `mailto:` without starting Godot
- iOS native handler that opens Mail from cold and warm quick actions
- Demo project with runnable Android and iOS export presets
- GitHub Actions release workflow that builds AAR + xcframework zip on `v*` tags
